Cloud Backup

Gmail দিয়ে লগইন করলে এই অ্যাপের তথ্য আপনার Firebase অ্যাকাউন্টে সেভ হবে। পরিবর্তন হলে স্বয়ংক্রিয়ভাবে সিঙ্ক করার চেষ্টা করবে। প্রথমবার Cloud ব্যবহার করতে অ্যাপটি Firebase Hosting-এর মতো HTTPS ওয়েবসাইটে চালু করতে হবে।

এখনো লগইন করা হয়নি।

সম্পূর্ণ ব্যাকআপ ডাউনলোড

ফোনে JSON ফাইল হিসেবে সব তথ্য সংরক্ষণ করুন। নিরাপত্তার জন্য মাঝেমধ্যে ডাউনলোড করে রাখুন।

আগের ব্যাকআপ ফিরিয়ে আনুন

শুধু এই অ্যাপের JSON ব্যাকআপ ফাইল নির্বাচন করুন। Restore করলে বর্তমান তথ্যের জায়গায় ব্যাকআপের তথ্য বসবে।
